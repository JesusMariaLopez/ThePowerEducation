Proyecto MERCAROPA

- Se trata de evaluar las ventas y los importesbfacturados de unamultinacional de mercadeo de ropa
- Se obtienen los datos a partir de un fichero CSV (Datos originales.csv)
- A continuacion se carga este CSV y se procede a la transformacion y limpieza de datos en la hoja del libro de excel llamada (Tabla Depurada).
- En el mismo libro de excel se adjunta otra hoja con aclaraciones de transformacion y limpieza de datos (Analisis EDA)
- Tenemos como fase siguiente la hoja (Analisis EDA) con el analisis EDA realizado mediante tablas dinamicas de varios factores de la empresa comercializadora
- Finalmente se incluye otra hoja (Dashboard), donde se muestra la evolucion y analisis de los datoos mediante KPI y GRAFICOS varios.
